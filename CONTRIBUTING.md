# Contributing to Knorvia

Thank you for improving Knorvia.

1. Create a focused branch and keep changes scoped to one concern.
2. Add or update tests for behavior changes.
3. Run the Python and Web checks documented in `README.md`.
4. Keep product-facing text, package names, environment variables, storage
   keys, and protocol names inside the `Knorvia` / `knorvia` namespace.
5. Preserve license headers and update `THIRD_PARTY_NOTICES.md` when adding
   third-party code or assets.

Commit messages should state the user-visible outcome. Pull requests should
describe the problem, the solution, verification performed, and any migration
or compatibility impact.
