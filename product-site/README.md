## 运行与构建

静态 HTML / CSS / JavaScript，发布时不需要 Node 服务。

- `npm run build`：从 scripts/orbit-content.cjs 生成首页，复制锁定版本的 Three.js。
- `npm run preview`：本地 http://127.0.0.1:4490 。
- `npm run check`：通过已安装的 Google Chrome 做真实交互验收。
- `node scripts/check-orbit-interaction.cjs`：验证复制、触屏翻页、图片重试、窗口焦点与按钮光效交互。
- `node scripts/check-orbit-review.cjs`：验证快速再次激活、缩放与拖动、键盘边界、概览页划动、短屏阅读、44px 手机按钮、照片区域滚页与下载链接复制。
- `node scripts/check-orbit-flow.cjs`：用真实 Chrome 场景验证 60Hz 帧输入、慢帧时钟、暂停恢复、真实 WebGL 上下文中断恢复、平滑重置及减少动态效果。
- `node scripts/check-orbit-finish.cjs`：验证当前章节不闪动或丢失阅读位置、快速翻页与章节标记对齐、动态效果偏好切换、看图适应/放大，以及入场中途关闭的连续性。
- `node scripts/check-orbit-life.cjs`：验证三条斑纹小鱼分布、独立照片姿态、跃出与落水、小船经过、暂停和减少动态效果、手机小景避让。
- `node scripts/package.cjs <版本号>`：将明确列入清单的静态文件打包至 work/product-orbit-20260909/deploy-<版本号>/，生成文件散列和发布清单。

构建使用相邻 web/node_modules 的 React / Lucide 生成图标，React 不发送到浏览器。Chrome 可用 CHROME_BIN 指定；验收地址可用 SITE_URL 指定，验收报告目录可用 SITE_CHECK_OUT 指定，避免覆盖历史验收记录。

## 结构与动效

- orbit-scene.js：所有展板共用倾斜轨道，朝向随切线改变；真实深度遮挡、双面图片、射线点击、拖动惯性、悬停减速和暂停控制。
- orbit-objects.js：细分圆柱曲面、原图标轮廓重建的立体折面、缓慢流体背景。图标采用项目现有高清原稿的纸纹和颜色，贴合到独立折面上。它是为有限视差展示重建的浮雕，不是原始工业建模文件。
- orbit-water.js：几何波面、带深度的折射缓存、水下颜色衰减和水线。底座实际位于水面以下，K 折面位于水面以上；照片按每个片元的世界坐标连续跨越水面。折射采用屏幕空间采样。沙滩具有真实高度，低处形成透水的湿沙边缘。
- orbit-life.js：三条珍珠白鱼身、柔和背斑与半透明鱼鳍的小鱼在各自水域随机巡游，偶尔跃出水面，落水带出细小水珠和涟漪；一个双色泳圈随实际波面浮动，两艘小帆船错开时间从角落经过。手机保留两条鱼和更小的船、泳圈，短屏隐藏水上小景。随机路线在每次访问时播种，全部动作共用场景时钟，没有独立计时器、点击目标或新增资源请求。
- orbit-app.js：每类独立四页的介绍、实机放大、链接历史、键盘导航与焦点恢复。窗口内箭头只翻当前主题的页，不切换照片。
- orbit-textures.js：后台解码并限制展示纹理尺寸，保留原图；浏览器不支持 ImageBitmap 时使用原有图片加载器。场景启动时分批上传纹理，第一次实际绘制后才显现。
- orbit.css：单视口布局、触控适配、减少动态效果和减少透明效果支持。

渲染限制像素密度与最高帧率。窗口后台、手动暂停和系统减少动态效果设置均会停止自主动画，用户操作后只补绘必要帧。WebGL / 资源失败时保留品牌和功能导航；禁用 JavaScript 时仍有六类说明、实机图片和公开下载链接。

手机和桌面使用同一个 60fps 预算，并保留帧间余量，避免旧移动端 45fps 门限在 60Hz 屏幕上落成隔帧绘制。流动时钟记录可见期间的实际经过时间，物理积分单独限幅；暂停、后台和 WebGL 中断恢复均重置时间起点。正在展开时暂停不会强行跳到展开终态，重置视角沿较短角度缓动归位。

流场采用连续二阶导数的噪声插值与两层大尺度云色，减少高频运算和条纹。水面使用三组缓慢交叠的波，最多保留三个渐入、衰减的触水涟漪；前一次涟漪不会在下一次触摸时立即消失。折射缓冲最高 1440×1080、倍率最高 1.15，深度边缘对有效折射渐进混合；屏幕坐标仍按实际绘制缓冲归一化。导航和按钮的聚光位置采用可插值 CSS 属性，指针停止后没有新增 JavaScript 绘制循环。

照片以单独的弯曲侧壁表现薄边，沿用共用材质和既有渲染通路。照片表面的缎面高光方向来自场景主光；法线、视线与悬停缓动决定细边反射。正面高光更窄更轻，背面更安静；品牌图和真实实机图片没有重绘。没有新增环境贴图、后处理目标或独立动画循环。

水面覆盖范围跟随视口计算，背景流体只绘制到折射缓存一次。可见照片标签才更新位置，避免隐藏标签反复写入页面。性能检查使用本机 Chrome，不能当作实际访客的性能统计。

照片保留共同轨道，同时按各自错开的相位轻微起伏和侧倾，转向时有有限的姿态滞后。选中和悬停时逐渐停稳，暂停保留当前浮动姿态。显卡恢复后完成首次资源绘制再显现，温启动耗时不计入动画时钟；系统减少动态效果的切换即使发生在手动暂停时，也会补绘静止姿态。

## 内容与来源

## 发布与回退

产品域名为 https://knorvia.xyz 。资源发布到 /r/<版本号>/；模块、封面与实机图片都从同一版本目录解析。上传后核验散列，最后原子替换首页。

保留上一版首页和资源，回退仅需恢复首页。依赖、脚本、测试资料、生成提示词和工作日志不会被上传。产品发布不修改模型中转服务器或桌面应用。

环绕默认留出更宽间距，自由探索时最前方照片显示功能名。直接抓住一张照片沿圆周拖动，整圈旋转；向外拖则同步展开，向中心拖则收拢。底部导航沿最短方向把对应照片转到前方并停留，再点照片、其名称或再次激活当前导航可查看详情；第二次激活无需等待照片完全停止。拖动会解除定位；手机明确纵向滑动交给浏览器滚页，包括从照片上起手，保留原生惯性。没有距离按钮或滑杆。

介绍卡片最多宽 480px。六类各自有四页，共 24 页，包含实机概览、具体能力、操作方式与场景示例。右上箭头、底部章节、左右键和 PageUp / PageDown 都只翻当前功能，首尾页停止；翻页不改变 URL，也不切换背景选中的照片。关闭再打开从概览开始。内容维护入口为 scripts/orbit-content.cjs；公开版与开发版、模型输入与费用范围保持明确。

正文以少量错开的层次沿翻页方向进入，底部亮线连续移向当前章节；重复选择当前页保留阅读位置，连续切页取消旧动画。关闭弹窗从屏幕当前可见的位移、缩放与透明度继续，不会在入场中途突然跳回单位缩放。中文标题放松字距，以两段短遮罩完成首屏展开；背景文字随弹窗轻缓退场。

触屏横向划动介绍正文可翻页，纵向划动阅读长文；窗口打开时背景停止滚动。示例可以复制，权限不可用时选中文字并提示；实机图片加载失败会显示重试入口。窗口关闭有退出过渡，随后恢复焦点；过渡过程中切换主题会撤销过期的关闭操作。

概览图片也支持横向划动翻页，识别划动后只抑制同次手势的点击。实机大图先适应窗口，提供放大、缩小和恢复适应；手机可放至原始像素并原生拖动浏览，桌面可用鼠标拖动、双击或 `+` / `-` / `0` 操作。子窗口关闭恢复到原入口，浏览器返回关闭父详情时同时关闭大图。缩放与翻页边界保持可用的键盘焦点。

手机主操作采用 44px 点击范围，并为系统安全区域留白；短屏同时调整高度与上限，844×390 横屏保留至少 180px 阅读区域。详情入场只移动实体面板，背景标题与导航淡出，避免文字叠影。下载窗口标明 Windows，并可复制公开下载页链接，剪贴板被拒绝时提供可选中的链接。

小预览通过 720 / 1440 的响应式图片选择合适尺寸，大图始终读取 1440 原图；发布清单包含两组图片。六类四页内容、原生玻璃透明度及公开下载 v1.0.0 保持原有约定。

实机入口使用白色磨砂浮层与蓝灰文字，下载按钮保留深色主操作层级。大图适应窗口时把细边留在图片本身，放大后恢复完整滚动底面；不改变真实图片像素或可操作区域。下载链接复制区与说明共用左边线。

下载与实机按钮参考 [Sylva](https://threeui.com/hero/sylva) 的细亮边缘和底部聚光，自行用 CSS 实现。高光随指针移动，按下收紧、松开回弹；图标按钮使用轻量珠光和有方向的反馈。没有复制参考站受保护的渲染代码，没有给按钮新增 WebGL 上下文；指针事件按帧合并写入，静止时不运行按钮绘制循环。键盘与触屏保留相同操作；减少动态效果时保留静态质感，减少透明效果时采用实色。
