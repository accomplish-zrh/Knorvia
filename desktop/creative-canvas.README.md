# Knorvia 创作画布

2026-09-10 · 可选创作流程

## 从哪里打开

- 创作台右上角的「创作画布」：使用完整画布空间，返回后继续使用原有图片、视频与分镜创作台。
- 对话右侧工作面板的「创作画布」：边聊边编辑。画布内点击「引用到对话」，再输入自己的要求发送，Agent 就能读取同一张画布。

两处打开的是个人资料库里的同一份画布，不会复制出互相分离的数据。没有增加一级导航。

## 从想法到连续镜头

1. 新建画布，在右侧填写共同上下文，例如角色、风格和统一要求。
2. 添加提示词节点，上传参考图片，或从个人资料库选图。
3. 添加图片/视频节点，选择创作台已配置的对应模型。拖动卡片调整位置，拖动圆点连接，也可在节点详情里选择上游与用途。
4. 在生成节点里点击「生成这个节点」。连线和保存本身不会提交生成。
5. 等图片生成完成后，将它连到视频的「首帧」；等视频完成后，将它连到下一段视频的「首帧」，下一段生成时会解码前一段的真实尾帧，自动存入资料库并作为首帧引用。

| 上游 → 下游 | 用途 |
| --- | --- |
| 提示词 → 提示词/图片/视频 | 继承文字上下文 |
| 参考图片/已生成图片 → 图片 | 参考图，最多 6 张 |
| 参考图片/已生成图片 → 视频 | 首帧或尾帧，各最多 1 张 |
| 已完成视频 → 视频 | 提取真实尾帧作为下一段首帧 |

共同上下文、文字上游和本节点提示词会一起传给模型。参考素材固定到资料库的具体版本。模型不支持某种输入、上游未完成或素材已失效时，会明确拒绝，不会悄悄丢掉参考图继续生成。

## 和 Agent 一起使用

可以发送这样的要求：

> 把当前画布整理成三个连续镜头，保持角色和光线一致。先补齐提示词和连线，不生成。

> 用当前画布已选节点的模型生成图片，完成后再生成后续视频。

Agent 通过 `media_canvas` 工具执行 `list/create/read/save/generate`，沿用创作台已有的模型、任务和素材管线。先读取当前版本再编辑；模型连接必须已启用「允许 Agent 使用」。生成使用你所配置提供商的额度。

外部 Agent 可通过已有创作 CLI 的 `tools.describe` 查询 `media_canvas`，再使用 `tools.call` 调用；详见同目录 `creative-cli.README.md`。

## 保存与恢复

- 修改后自动保存，顶部显示当前状态。支持撤销/重做、自动排布，以及画布 JSON 导入导出。
- 画布文件在个人资料库的 `画布/<id>.knorvia-canvas.json`；上传图放在「画布素材」目录。图本身不保存密钥或整段媒体数据。
- 两个窗口同时编辑时，旧版本不会覆盖新版本。冲突窗口可先导出草稿，再「读取最新」。该窗口的未保存草稿在刷新后可恢复；关闭整个窗口前仍应完成保存或导出。
- 生成提交重试复用同一请求。结果未知时不自动再次提交，也不能通过移除节点绕开正在执行的任务；请在创作台查看原任务状态。
- 每张画布最多 80 个节点、200 条连线；导入文件最多 2 MiB，上传参考图最多 20 MiB。画布定义不包含媒体文件，导出 JSON 的素材引用需要同一资料库。

## 参考与实现

参考大雄的 [Infinite-Canvas](https://github.com/hero8152/Infinite-Canvas) 的无限画布和素材串联思路。Knorvia 的实现独立编写，未复制该项目的代码或美术资源；节点编辑器采用 [React Flow](https://reactflow.dev)，随包附带相关依赖许可。

此版包含手动节点生成和 Agent 顺序调用；没有增加全图自动执行调度器。原创作台的队列、视频工作流继续保留。
